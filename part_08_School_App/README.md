
# School Management App

## Project Description
This is a simple School Management App developed using Python.

## Features
- Calculate student average marks.
- Assign grades to students.
- Generate student reports.
- Check student attendance.
- Use Python modules and packages.

## Project Structure
- school_tools.py: Contains student report functions.
- main_module_test.py: Tests the custom module.
- school/: Contains the school package.
- grades.py: Calculates average and grades.
- attendance.py: Checks attendance.
- main.py: Runs the School Management App.

## Technologies Used
- Python
- Python Modules
- Python Packages
- Virtual Environment
- Requests Library

## How to Run
1. Activate the virtual environment.
2. Install requirements.
3. Run main.py.
