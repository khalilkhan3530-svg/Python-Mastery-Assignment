
# School Manager

A Python-based School Management System.

## Features
- Add students
- Add student marks
- Generate report cards
- Display class rankings
- Save and load student data using JSON

## Requirements
- Python 3
- pytest

## How to Run

Run the application:

```bash
python main.py
```

Run tests:

```bash
python -m pytest -v
```
